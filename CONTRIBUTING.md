# Conventional Commits

This project follows the [Conventional Commits](https://www.conventionalcommits.org/) specification.

## Format

```
<type>(<optional scope>): <description>
```

- Use the imperative mood: "add", not "added" or "adds".
- Keep the description lowercase and without a trailing period.
- One commit per exercise or sub-exercise.

## Types

- `feat`: new feature or exercise implementation
- `fix`: bug fix
- `docs`: documentation only (reports, README, guides)
- `style`: formatting, no code change
- `refactor`: code change that neither fixes a bug nor adds a feature
- `test`: adding or updating tests
- `chore`: tooling, configs, gitignore, maintenance

## Examples

```
feat: implement transfer learning baseline
docs: add lab report
chore: update gitignore
```
